
# 🌍 Language-Detection-Model

This project is a **machine learning model** that predicts the language of a given text input.  
It uses **NLP preprocessing** and classification techniques to detect languages based on the dataset provided.

---

## 🚀 Features
- Detects the language of text from multiple supported languages.
- Trained using the **language.csv** dataset.
- Implements preprocessing (tokenization, vectorization).
- Jupyter Notebook included for step-by-step exploration and training.

---

## 📂 Repository Structure
- **`language.csv`** → Dataset containing text samples and their corresponding languages.  
- **`model.ipynb`** → Jupyter notebook for preprocessing, training, and evaluating the model.  
- **`README.md`** → Documentation (this file).
